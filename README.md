Harbour Spotter — an original spot-the-difference game: two near-identical harbour pictures side by side, 7 differences per round, 3 rounds (sunset, night, morning), click to mark a difference, timer, hints (H), score, win and time-up screens. Keyboard + mouse, plays offline in a desktop browser from its own files, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — Space/click to start, click a difference on either picture, H for a hint, P to pause, R to restart, M to mute the beeps.
